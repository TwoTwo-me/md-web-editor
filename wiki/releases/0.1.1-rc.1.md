# 0.1.1-rc.1 verification candidate

This is a candidate, not final privacy acceptance.

- Live prose supports pointer editing; reference definitions are shared across blocks. Live footnotes navigate to their source definition, and reading footnotes scroll within the document.
- Task toggles use parsed list positions, excluding literal brackets and code fences while supporting nested, quoted and loose lists.
- Recovered journal revisions are removed after successful save. Stale navigation no longer raises false save dialogs.
- Graph navigation preserves canonical missing paths and represents ambiguous links as unresolved choices. Pending search is cancelled on teardown.
- Committed `public/themes/*.json` files populate Settings at build time. Quiet Violet selection persists without runtime fetching.
- Initial offline installation no longer shows a spurious update banner. Cache identity includes an asset digest; public theme files are included in the offline manifest.

Before source push: `pnpm test` passed 56 tests across 11 files; `pnpm check` and `pnpm build` passed. Computer Use on the production preview exercised live task editing, reference-link navigation and theme selection. No initial-install update banner appeared. The JavaScript bundle is approximately 304 KiB compressed; no Lighthouse score is claimed.

Pending final acceptance: fresh visual review, candidate deployment verification, dedicated-origin decision, and remediation of the initial public commit author metadata. See [origin isolation](../decisions/003-origin-isolation.md). Subsequent verification records will name the exact built commit.
