# 0.2.0 — All-file links

Settings can expose every supported ordinary file name in the explorer, quick switch and wiki completion. The existing hidden/VCS directory exclusions remain; all extensions are indexed without reading their contents. The setting defaults off, preserving the previous note-only discovery experience. Already written file links remain usable regardless of the discovery setting.

New wiki links are saved with an explicit path from the selected folder root: `[[/자료/설명서.pdf|설명서]]`. Completions, link commands and newly typed/pasted prose links use this format. Existing untouched content is not rewritten. Code, escaped literals, raw HTML and standard Markdown links are excluded from automatic wiki conversion. A root-qualified missing path never falls back to an unrelated file with the same basename. Characters such as `#`, `%` and square brackets are encoded in the stored target, while labels remain readable. Ambiguous targets remain unresolved for the user to choose.

Non-Markdown links and graph nodes open the local attachment dialog. Valid raster images render locally; text, HTML, SVG and code render as plain text only, with a 200 KiB preview limit. Other formats, including PDF/Office/archive files and oversize images, have an explicit download action preserving the complete file bytes. The browser cannot launch a selected original file in an operating-system application. No remote viewers, uploads or new network permissions were added. Closing the dialog releases its blob URLs.
