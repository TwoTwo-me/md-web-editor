# 0.4.0 — Installable offline application

Chrome can install `md-web-editor` as a standalone application using the native install dialog and the boxed `.md` icon. Application manifest and icons are included in the offline asset cache. The existing image/network policy remains unchanged; icons are embedded in the manifest. Welcome text reports offline preparation and failure instead of treating service-worker registration as completed caching.

Local native Chrome installation, fresh-window launch with the QA server stopped, local-folder editing/autosave, wiki links and the right graph panel have been observed using generated notes only. Generated-worker regressions cover the complete precache, offline navigation, rejected installation, unknown-resource exclusion and explicit update activation. Final source/review/deployment acceptance follows the frozen product commit. See [ADR 005](../decisions/005-install-offline.md) for the capability boundaries.
