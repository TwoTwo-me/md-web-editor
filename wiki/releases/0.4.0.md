# 0.4.0 — Installable offline application

Chrome can install `md-web-editor` as a standalone application using the native install dialog and the boxed `.md` icon. Application manifest and icons are included in the offline asset cache. The existing image/network policy remains unchanged; icons are embedded in the manifest. Welcome text reports offline preparation and failure instead of treating service-worker registration as completed caching.
