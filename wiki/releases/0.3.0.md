# 0.3.0 — Split panels

Notes and graphs now share an Obsidian-style system of tab groups. Tabs can move/reorder, create recursive left/right/top/bottom splits through edge drops, or duplicate into right/down groups. The tab/group menu exposes equivalent non-drag controls, plus close and merge. Dividers support pointer resizing, keyboard arrows, Home/End, and double-click reset. Narrow workspaces retain the layout behind a labeled group selector.

One document session and autosave queue serves all views of the same note. Views retain independent modes, selection, scroll and undo state, with minimal mirrored content updates. Closing a final view preserves unsaved/conflicted work. Graph navigation can update a neighboring note panel while leaving the graph visible. Graph instances survive moves and resizes; their force center responds to visible geometry and their SVG markers are unique.

Layout metadata is stored locally per vault and restored after reopening the folder, with bounded validation and missing-file pruning. No note contents, requests, uploads or external viewers were added. See [ADR 004](../decisions/004-split-panels.md).

Local verification in progress: 129 tests, TypeScript/Biome and production build pass. Real browser actions verified graph edge drag into a right split, keyboard divider resizing, graph-to-left-note navigation, and layout restore. Final product SHA, native-folder autosave, visual review and public deployment receipts follow after acceptance.
